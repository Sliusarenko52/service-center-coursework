# Вебсистема обліку заявок сервісного центру (Варіант 7)

Навчальна курсова робота з дисципліни «Веб-технології та веб-дизайн» (Національний університет «Одеська політехніка», кафедра інформаційних систем, 2026).

## Призначення та ролі
Система автоматизує приймання, діагностику, погодження вартості робіт та облік використаних деталей у сервісному центрі. Підтримуються три ролі з розмежуванням прав доступу на сервері:
- **Клієнт (`CLIENT`)** — реєстрація заявок із зазначенням обладнання та несправності, перегляд лише власних заявок, погодження або відхилення переліку робіт і вартості, скасування заявки.
- **Приймальник (`RECEIVER`)** — перегляд усіх звернень, пошук і фільтрація, призначення виконавця, фінальне закриття виконаних заявок.
- **Виконавець (`TECHNICIAN`)** — перегляд лише призначених йому робіт, фіксація діагностики, додавання видів робіт та списання деталей зі складу, фіксація результату виконання.

Реалізовані ускладнення:
1. **Облік деталей** (`parts` та `request_parts`) із перевіркою залишків на складі та серверним перерахунком загальної вартості.
2. **Контроль версії запису (оптимістичне блокування)** через поле `version` із поверненням `409 Conflict (VERSION_CONFLICT)` при одночасному редагуванні двома працівниками.

## Вимоги до середовища
- ОС: Windows 10/11 (або Linux / macOS)
- **.NET SDK 10.0** (`dotnet --version` >= 10.0)
- Сучасний веббраузер (Google Chrome / Microsoft Edge)
- Додаткова СКБД не потрібна: використовується вбудована реляційна СКБД **SQLite** (`Microsoft.Data.Sqlite`).

## Налаштування та запуск (із чистого каталогу)
Усі команди виконуються з кореневого каталогу проєкту (`d:\web_kurs`):

1. **Відновлення залежностей та збирання:**
   ```powershell
   dotnet restore ServiceCenter.sln
   dotnet build ServiceCenter.sln
   ```

2. **Конфігурація (опціонально):**
   За замовчуванням база даних створюється автоматично у `src/ServiceCenter.Web/App_Data/service_center.db`. Для перевизначення рядка підключення скористайтеся прикладом із `.env.example`:
   ```powershell
   $env:ConnectionStrings__DefaultConnection="Data Source=App_Data/service_center.db"
   ```

3. **Запуск вебсистеми:**
   ```powershell
   dotnet run --project src/ServiceCenter.Web/ServiceCenter.Web.csproj --urls http://localhost:5080
   ```
   Під час першого запуску автоматично створюється схема БД (7 таблиць та індекси) й завантажується початковий демонстраційний набір даних (користувачі, склад деталей, 10 заявок у різних станах).

4. **Відкриття в браузері:**
   Перейдіть за адресою `http://localhost:5080`. Перевірка готовності сервісу та БД: `GET http://localhost:5080/health`.

5. **Зупинка:** натисніть `Ctrl + C` у терміналі.
